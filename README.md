# Medical Reps Portal 🏥

Beautiful glassmorphism-styled medical representatives management system.

## Features ✨

- 📅 **Weekly Planning**: Plan 50 doctor visits per week
- 📝 **Daily Reports**: Track daily activities and visits
- 🏥 **Hospital Tracking**: Manage relationships with private hospitals
- 📊 **Manager Dashboard**: Overview of all activities and analytics
- 🎨 **Beautiful UI**: Modern glassmorphism design with animated gradients

## Deployment 🚀

### Deploy to Vercel

1. Install Vercel CLI:
```bash
npm install -g vercel
```

2. Deploy:
```bash
cd medical-reps-portal
vercel
```

### Deploy to Netlify

1. Install Netlify CLI:
```bash
npm install -g netlify-cli
```

2. Deploy:
```bash
cd medical-reps-portal
npm run build
netlify deploy --prod --dir=dist
```

## Local Development 💻

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
